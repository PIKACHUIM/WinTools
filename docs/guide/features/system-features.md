# 功能管理

包含两个页签：**系统功能**（DISM 可选功能）与 **版本渠道切换**。

## 系统功能

枚举系统中全部可选功能及其启用状态，逐项启用/禁用。实测 Windows 11 上约 **135 项**。

![系统功能](/screenshots/features-systemfeatures.png)

**用法**：

- 功能按用途分成**虚拟化与容器 / 服务器与角色 / 开发与运行时 / 打印与传真 / 媒体与播放 / 安全与加密 / 网络与共享 / 其他**，点击分类标题展开或收起。
- 常见功能显示中文名称与一句说明（例如「打印基础功能 — 打印服务与打印机管理」），冷门功能保留 DISM 原始名。
- 右侧是**开关**：先把要改的功能拨到目标状态，顶部会提示「N 项待应用」，确认后点 **应用** 一次性执行；分类标题右侧的「全选」可以整组切换。
- 搜索框输入关键字（如 `Hyper`、`Telnet`、`Printing`）实时过滤。

**实现**：通过 `dism.exe /English /Get-Features /Format:Table` 解析输出（强制英文标签，避免不同系统语言的解析差异），启用/禁用调用 `/Enable-Feature` 与 `/Disable-Feature`。相比直接调 `DismApi`，这种方式对小规模操作足够快，也避免了 COM/原生互操作的复杂度。

::: tip 为什么不用 DismApi
`DismApi` 需要按会话打开映像、处理回调与内存，代码量是命令行解析的数倍；而枚举 137 项的耗时主要花在 DISM 自身初始化上。当前实现约 1 秒完成，后续若要做批量离线操作再切换到原生 API。
:::

::: warning 常见副作用
- 禁用 **.NET Framework 3.5** 会导致部分老程序无法启动。
- 禁用 **Windows Search** 后开始菜单搜索与资源管理器搜索失效。
- 禁用 **Printing** 相关功能后打印机无法使用。
:::

## 版本渠道切换

读取当前系统的 SKU、版本号、安装类型与激活状态，并可通过产品密钥切换版本（专业版 / 家庭版 / 企业版等）。

![版本渠道切换](/screenshots/features-systemfeatures.png)

**信息读取**：

| 项 | 来源 |
| --- | --- |
| 产品名称 / 版本 / 内部版本 | `HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion` |
| 激活状态 / 部分密钥 | `SoftwareLicensingProduct`（WMI） |
| 安装类型 | `InstallationType` 注册表值 |

**切换版本**：输入 25 位产品密钥 → 调用系统自带的 `changepk.exe` 向导完成切换。

::: danger 切换版本前请务必确认
- 调用的是**系统原生向导**，过程中会要求重启，界面不可控（属于正常现象）。
- 密钥必须与目标版本匹配，否则向导会失败；本工具不提供密钥，也不做任何激活绕过。
- 降级（如专业版 → 家庭版）通常需要重装，向导不一定支持。
- 建议先在「设置 → 系统 → 激活」里记录当前密钥或数字许可证绑定情况。
:::
