## 三个通用交互

所有模块页都遵循同一套操作习惯，学会一处即可通用：

**① 操作栏在左上，批量操作先勾选**

![服务管理](/screenshots/startup-services.png)

- `刷新` 重新读取系统状态
- 主按钮（蓝色）为当前页签的主要动作，如「安装所选」「设为自动」
- 次按钮为配套动作，如「设为手动」「删除」
- 有勾选框的页面会多出「全选」

**② 搜索框实时过滤**

输入即过滤当前列表（程序名、服务名、KB 号、驱动名均可），不需要回车。

**③ 单行操作在右侧**

每行最右是这一项自己的动作，如「启动/停止」「卸载」「删除」。执行中按钮会临时禁用，避免重复提交。

## 状态语义

| 颜色 | 含义 |
| --- | --- |
| 绿色 | 正常 / 已启用 / 运行中 |
| 琥珀 | 需注意（已禁用、系统默认、高风险项） |
| 红色 | 异常 / 失败 |
| 灰色 | 中性信息（版本号、发布名等） |

## 耗时操作都会给反馈

扫描、安装补丁、导出驱动、捕获镜像等操作会显示进度条与状态文字；失败时显示系统返回码或命令输出，方便针对性排查。
