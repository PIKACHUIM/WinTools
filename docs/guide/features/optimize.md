# 系统优化

把常见"优化"动作写成声明式条目：**先检测当前状态 → 勾选要改的项 → 一次应用 → 随时回滚**。

![系统优化](/screenshots/optimize.png)

## 条目组织

共 **124 项 / 7 个分类**：

| 分组 | 例子 |
| --- | --- |
| 隐私与遥测 | 关闭诊断追踪、禁用活动历史、关闭广告 ID、关闭系统推荐 |
| 性能与响应 | 高性能电源计划、关闭休眠（释放 hiberfil.sys）、关闭快速启动 |
| 资源管理器 | 显示文件扩展名、显示隐藏文件、打开文件资源管理器到此电脑 |
| 系统行为 | 关闭 UAC 提示音、调整菜单延迟、关闭自动播放 |
| 网络 | 关闭带宽限制、调整 TCP 设置、关闭传递优化 |
| 更新 | 暂停更新、关闭自动重启、关闭驱动自动更新 |
| 游戏 | 关闭 Game Bar、关闭全屏优化 |
| 任务栏 | 图标左对齐、隐藏搜索框、关闭开始菜单推荐 |
| 账户与安全 | 禁用自动运行、关闭远程协助、关闭 LLMNR |
| 开机引导 | 启动菜单等待时间、快速启动 |

每项都带 **风险等级**（低 / 中 / 高）与一句影响说明，例如"关闭休眠会删除 hiberfil.sys，双系统用户建议先关闭快速启动"。

## 操作流程

1. 进入页面自动**检测**，每个分类标题显示 `已启用 / 总数`，已生效的项右侧标「已应用」。
2. 三种勾选方式：逐项勾选；分类标题右侧「全选」；顶部 **全选** / **推荐项**（推荐项只勾选经过验证、副作用小的条目）。
3. 点 **应用** ——只处理"勾选了但还没生效"的项，逐条执行注册表/服务/命令动作，完成后自动重新检测。
4. 想撤销：取消勾选后点 **还原**，只回滚"已生效但被取消勾选"的项，按记录的原值恢复而不是"反向写死值"。

## 实现要点

每个条目是一段 JSON 声明，引擎按动作逐条执行：

| 动作 | 说明 |
| --- | --- |
| `RegSet` | 写 DWORD / 字符串 / 二进制，记录原值以便回滚 |
| `RegDeleteValue` / `RegDeleteKey` | 删除注册表值或键 |
| `ServiceStart` | 改服务启动类型（自动 / 手动 / 禁用） |
| `Command` | 执行外部命令（如 `powercfg`、`bcdedit`） |

检测与应用是两个独立步骤：检测只读，应用前会再核对一遍当前值，避免覆盖用户在此期间的手动修改。

## 注意事项

::: warning 这些项会影响系统行为
- **关闭快速启动**：开机会略慢，但双系统/多系统环境下更稳定。
- **关闭休眠**：会删除 `hiberfil.sys`（通常数 GB），"睡眠"仍可用。
- **暂停更新**：只是延后，建议设置明确的恢复时间。
- **服务启动类型**：本工具只调整明确标注过的服务，不会批量停用系统服务。
:::

条目数据在 `src/WinTools.Infrastructure/Rules/tweaks.json` 与 `tweak-groups.json`。
